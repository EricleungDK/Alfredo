### Fixed

- Host git's uncommitted-changes check (shown at `/go` start) and the write-tier git tools (`git_commit`, `git_switch`, `git_merge`, `git_push` approval fingerprints, commit and merge previews, the commit's intent-to-add diff) pass `--ignore-submodules=all` to `git status` and working-tree `git diff`, so a `submodule.<name>.ignore=none` setting can no longer make git run inside a submodule and apply a filter driver or config include from `.git/modules/<name>/config`. A staged submodule pointer change is still listed by the staged diff; `git_commit` with the submodule path named as a file now reports no change.
