### Added

- Chat replies show Markdown styled in the transcript: fenced code blocks (code rows cut at
  the pane width instead of wrapped, fence lines dimmed, an unfinished fence while
  streaming stays an open block), headings, `**bold**`, `` `inline code` `` and
  `-`/`*`/`1.` bullets. Unbalanced markup stays plain, your own messages stay as typed,
  and bidi controls in a reply show as `<U+XXXX>`.
