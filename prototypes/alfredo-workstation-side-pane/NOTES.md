# Alfredo Workstation Side Pane Prototype

Question: which persistent side-pane model better supports transparent agent/subagent work while the prompt pane remains dominant?

Variants:

- `cards`: compact live workstation cards with expandable operational detail.
- `table`: dense table/list with a selected detail inspector.

Open decision after review:

- Card-first with expandable details.
- Table-first with selected detail.
- Hybrid: cards for active/blocked agents, table for completed/history sessions.

This is a throwaway prototype. Once a direction is selected, fold the chosen interaction model into the real workstation UI and delete this folder.
